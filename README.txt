EDITABLE WEBSITE

Easy editing:
1. Open data.js in Notepad or VS Code.
2. Edit text, contact details, software list, project names, or featuredProject.
3. To add images, copy them into the assets folder and add their filenames in data.js.
4. Open index.html to preview.

Main files:
index.html  = page structure
style.css   = colors/layout
data.js     = easiest place to edit content
script.js   = gallery behavior
assets/     = portfolio images

To publish online, upload the whole folder to GitHub Pages, Netlify, Vercel, or your web host.
